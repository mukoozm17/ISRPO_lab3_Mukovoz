## Техническое задание

### Назначение

Автоматическое удаление однострочных комментариев `//` из исходных файлов C++.

### Функциональные требования

1. Плагин добавляет в палитру команд VS Code команду «Comment Cleaner: удалить // комментарии».
2. Команда обрабатывает весь текущий файл.
3. Удаляется весь текст от `//` до конца строки.
4. Не считаются комментариями и не изменяются:
   - `//` внутри строковых литералов (например, `"http://example.com"`);
   - `//` внутри блочных комментариев `/* ... */`.
5. Блочные комментарии `/* ... */` остаются без изменений.
6. Если открыт файл не на C++, плагин показывает предупреждение и ничего не меняет.
7. Если ни один файл не открыт, команда ничего не делает.
8. Все изменения применяются одной правкой, поэтому откатываются одним `Ctrl+Z`.

### Нефункциональные требования

- Плагин запускается только при вызове команды.
- Для работы не нужны внешние библиотеки.
