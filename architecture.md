
## Архитектура

### Состав плагина

| Компонент | Файл | Роль |
|---|---|---|
| Манифест | `package.json` | Объявляет команду, горячую клавишу и точку входа (`main`) |
| Точка входа | `src/extension.ts`, функция `activate` | Регистрирует команду, проверяет редактор и язык, применяет правку |
| Обработчик текста | `src/extension.ts`, функция `removeComments` | Принимает строку, возвращает строку без `//` комментариев |

Манифест и код связаны идентификатором команды `commentCleaner.remove`: он указан в `package.json` и в вызове `registerCommand`. Если идентификаторы не совпадают, команда появится в палитре, но не выполнится.

Функция `removeComments` не зависит от VS Code API, поэтому её можно проверять отдельно от остального плагина.

### Алгоритм `removeComments`

Функция проходит по тексту слева направо и находится в одном из трёх состояний. Главная идея: `//` считается комментарием только в состоянии «Код».

| Состояние | Что происходит | Переход |
|---|---|---|
| Код | Символ копируется в результат | `//` пропускается до конца строки; `/*` переводит в блок; `"` переводит в строку |
| Строка | Всё копируется как есть, `\"` пропускается парой | Закрывающая `"` возвращает в код |
| Блок `/* */` | Копируется целиком | После `*/` возврат в код |

### Структуры данных

- строка-накопитель `result`, в которую собирается итоговый текст;
- индекс `i` для посимвольного обхода исходной строки;
- диапазон `Range` (начало и конец документа), в который записывается результат.

### Последовательность работы

1. Пользователь вызывает команду `commentCleaner.remove`.
2. VS Code активирует плагин (вызывает `activate`) и запускает функцию команды.
3. Проверяется, что редактор открыт и язык файла `cpp`.
4. Текст файла читается методом `getText()`.
5. `removeComments` возвращает текст без `//` комментариев.
6. Строится диапазон «весь документ» и выполняется `editor.edit` с заменой текста.
7. Правка применяется целиком, что позволяет откатить её одним действием.
